
# PHP Lab

PHP хэлний лабораторийн ажлууд.

## Ашигласан технологи
- PHP
- XAMPP
- Apache
- MySQL
- phpMyAdmin

## Ажиллуулах заавар
1. XAMPP дээр Apache болон MySQL асаана.
2. php-lab хавтсыг C:\xampp\htdocs дотор байрлуулна.
3. phpMyAdmin дээр phplab өгөгдлийн сан үүсгэнэ.
4. database/phplab.sql файлыг Import хийнэ.
5. http://localhost/php-lab/ хаягийг нээнэ.
